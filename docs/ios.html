Install on iPhoneУстановка на iPhone

Resona for iOS is not in the App Store, so you install the .ipa file yourself. This is called sideloading. It is free and takes about ten minutes the first time.

Resona для iOS нет в App Store, поэтому файл .ipa ставится вручную. Это называется сайдлоад. Это бесплатно и в первый раз занимает минут десять.

checklistYou will needЧто понадобится

  • smartphoneAn iPhone or iPad on iOS 16 or neweriPhone или iPad на iOS 16 или новее
  • personAn Apple ID. A free one works, and it can be a spare accountApple ID. Подойдёт бесплатный, можно завести отдельный
  • computerA Windows PC or a Mac and a USB cable for the first installКомпьютер на Windows или Mac и кабель для первой установки

1. Download the app1. Скачайте приложение

Open the latest release on GitHub and download the file named Resona-ios-…ipa to your computer.

Откройте последний релиз на GitHub и скачайте на компьютер файл Resona-ios-…ipa.

download Latest releaseПоследний релиз

2. Install with Sideloadly2. Установите через SideloadlyEasiestПроще всего

Sideloadly is a free desktop app that signs the file with your Apple ID and puts it on your phone over the cable.

Sideloadly это бесплатная программа для компьютера. Она подписывает файл вашим Apple ID и ставит его на телефон по кабелю.

  1. Get SideloadlyСкачайте Sideloadly Download it from sideloadly.io and install it. On Windows, also install iTunes and iCloud from Apple's website, not from the Microsoft Store. Скачайте с sideloadly.io и установите. На Windows также поставьте iTunes и iCloud с сайта Apple, а не из Microsoft Store.
  2. Connect your iPhoneПодключите iPhone Plug it in with the cable, unlock it and tap Trust when it asks about this computer. Подключите кабелем, разблокируйте и нажмите Доверять, когда телефон спросит про компьютер.
  3. Drop in the fileПеретащите файл Drag the .ipa into the Sideloadly window, type your Apple ID and press Start. Enter your password and the two-factor code when asked. Перетащите .ipa в окно Sideloadly, введите Apple ID и нажмите Start. Когда попросит, введите пароль и код двухфакторной проверки.
  4. Trust yourself on the phoneРазрешите приложение на телефоне Go to Settings → General → VPN & Device Management, tap your Apple ID and then Trust. Откройте Настройки → Основные → VPN и управление устройством, выберите свой Apple ID и нажмите Доверять.
  5. Turn on Developer ModeВключите режим разработчика Go to Settings → Privacy & Security → Developer Mode, switch it on and restart. After the restart, confirm with Turn On. That's it, open Resona. Откройте Настройки → Конфиденциальность и безопасность → Режим разработчика, включите и перезагрузите телефон. После перезагрузки подтвердите Включить. Готово, открывайте Resona.
schedule
With a free Apple ID the app works for 7 days. After that it stops opening until you install it again the same way. Your music and settings stay. A paid Apple developer account makes it last a year. С бесплатным Apple ID приложение работает 7 дней. Потом оно перестанет открываться, пока вы не установите его заново тем же способом. Музыка и настройки сохранятся. С платным аккаунтом разработчика Apple подпись живёт год.

Without a computer: SideStoreБез компьютера: SideStore

SideStore lives on your phone and renews the app itself, so you only need a computer once, to set SideStore up. Follow their official guide, then in SideStore open My Apps, tap + and pick the Resona .ipa. Every few days, open SideStore and tap Refresh.

SideStore живёт прямо на телефоне и сам продлевает подпись. Компьютер нужен только один раз, чтобы его настроить. Следуйте официальной инструкции, потом в SideStore откройте My Apps, нажмите + и выберите .ipa Resona. Раз в несколько дней заходите в SideStore и нажимайте Refresh.

UpdatingОбновление

Download the new .ipa and install it over the old one with the same Apple ID. Don't delete the app first, or your favorites and settings go with it.

Скачайте новый .ipa и поставьте поверх старого с тем же Apple ID. Не удаляйте приложение перед этим, иначе вместе с ним пропадут избранное и настройки.

folder_open
Keep a backup. Turn on auto-export in Settings → Import / Export and Resona will save your favorites to Files → On My iPhone → Resona → Backups. Делайте резервную копию. Включите автоэкспорт в Настройки → Импорт / Экспорт, и Resona будет сохранять избранное в Файлы → На iPhone → Resona → Backups.

If something goes wrongЕсли что-то не так

"Untrusted Developer" when opening the app«Ненадёжный разработчик» при запуске

You skipped step 4. Trust your Apple ID in Settings → General → VPN & Device Management.

Пропущен шаг 4. Разрешите свой Apple ID в Настройки → Основные → VPN и управление устройством.

There's no Developer Mode in settingsВ настройках нет режима разработчика

It only shows up after a sideloaded app is installed. Finish the install first, then look again.

Он появляется только после установки приложения через сайдлоад. Сначала закончите установку, потом проверьте ещё раз.

The app stopped opening after a weekЧерез неделю приложение перестало открываться

The free 7 day signature ran out. Install it again with Sideloadly, or tap Refresh in SideStore. Nothing is lost.

Закончилась бесплатная 7-дневная подпись. Поставьте приложение заново через Sideloadly или нажмите Refresh в SideStore. Ничего не потеряется.

Sideloadly says I have too many appsSideloadly пишет, что приложений слишком много

A free Apple ID can keep only 3 sideloaded apps at once. Remove one you don't use, or sign in with another Apple ID.

С бесплатным Apple ID одновременно можно держать только 3 приложения через сайдлоад. Удалите ненужное или войдите под другим Apple ID.

The app crashes on launchПриложение вылетает при запуске

Open an issue on GitHub and attach the crash report from Settings → Privacy & Security → Analytics & Improvements → Analytics Data, the file that starts with Resona.

Создайте issue на GitHub и приложите отчёт о сбое из Настройки → Конфиденциальность и безопасность → Аналитика и улучшения → Данные аналитики, файл, который начинается с Resona.
